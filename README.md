# Resolve Ingest

A planned Rust desktop application for ingesting DJI Osmo Action 4 footage on Linux: archive untouched originals to a mounted Samba share, create editing copies with PCM audio, and verify every completed operation.

The application remembers the SD-card source, editing destination, and NAS archive directory. It keeps originals intact and supports progress reporting, actionable errors, and retries after interruption. A polished dark interface with accessible controls and clear per-file feedback is part of the release requirements.

See [the project plan](docs/project-plan.md) for architecture, workflow, implementation milestones, and acceptance criteria. Implementation has not started.
